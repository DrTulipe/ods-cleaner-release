# ODS Cleaner

Nettoyage, surveillance et entretien de votre PC Windows.

## Télécharger

**[Télécharger la dernière version](https://github.com/DrTulipe/ods-cleaner-release/releases/latest)**

Sur la page qui s'ouvre, cliquez sur `ODS-Cleaner-Setup-x.y.z.exe`, puis lancez le fichier téléchargé.
Windows 10 ou 11, 64 bits.

## Mises à jour

Une fois installé, ODS Cleaner peut se mettre à jour tout seul :
**Paramètres → Mises à jour d'ODS Cleaner → Rechercher automatiquement**.
Chaque nouvelle version est signée ; ODS Cleaner vérifie cette signature avant de l'installer.
